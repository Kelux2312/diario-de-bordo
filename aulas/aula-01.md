Aula 01 - Na primeira aula, aprendi a diferença entre Git e GitHub: o Git controla as alterações nos arquivos, enquanto o GitHub permite armazenar projetos online e trabalhar em equipe.
Também aprendi que os commits registram as mudanças feitas no projeto, com mensagens explicando o que foi alterado.
Conheci as branches, que permitem trabalhar em mudanças separadamente, e os pull requests, usados para solicitar a revisão do código. Por fim, entendi que o merge serve para juntar as alterações de diferentes branches.
